## Priority key

- **P0:** Correct misleading or unsafe behavior before any use of the current “trusted repair” promise.
- **P1:** Needed if a validated narrow product is pursued.
- **P2:** Cleanup after product decision; not a reason to continue investing.
- **P3:** Revisit only with a concrete user requirement.
